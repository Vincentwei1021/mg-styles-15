每支 10 秒的片子都是 AI 按一段提示词写代码做出来的：画面、动画、配乐和音效全部由代码生成。 下面每种风格都附上成片、风格说明、完整提示词和全部源码。提示词可以直接复制，拿去做你自己的片子。Each 10-second film was made by an AI writing code from a single prompt: the picture, the animation, the music and the sound effects all come from code. Every style below comes with the film, a description, the full prompt and all of the source. Copy a prompt and use it to make your own film.

怎么用这些提示词How to use the prompts

  1. 在一个空文件夹里打开能写代码、能执行命令的 AI 助手（例如 Claude Code）。本机需要 Node、Chrome 和 ffmpeg，3D 那支还要 Blender。Open an AI assistant that can write code and run commands (for example Claude Code) in an empty folder. The machine needs Node, Chrome and ffmpeg; the 3D film also needs Blender.
  2. 复制某种风格的提示词，整段发给它。Copy the prompt of a style and send all of it.
  3. 想换成自己的内容：改 Creative seed 里的故事、品牌名、文案和配色，或者改 Output 里的尺寸和时长。Signature features 那段别删，它决定这种风格能不能被一眼认出来。To make it your own, change the story, brand name, copy and colours in Creative seed, or the size and length in Output. Keep Signature features: it is what makes the style recognisable at a glance.
  4. 想再提高：成片出来后，另开一个 AI 用 rubric.md 评审，把意见贴回去改一轮。要写一种新风格，照 template.md 填四段。To push it further, have a second AI review the film with rubric.md and paste the review back for another round. To write a new style, fill in the four sections of template.md.

自己跑源码Run the source yourself

# 在仓库根目录# from the repository root
npm install
pip install -r requirements.txt
python3 demos/01-flat-vector/audio.py        # 合成配乐 → out/audio.wav# music and SFX → out/audio.wav
node harness/render.mjs demos/01-flat-vector # 逐帧渲染 → out/video.mp4# render every frame → out/video.mp4
python3 -m http.server 8000                  # 拖时间轴预览：# scrub preview: localhost:8000/harness/preview.html?demo=01-flat-vector

每支片是一个网页，按时间画出任意一帧（window.renderAt(t)）；渲染脚本用无头 Chrome 逐帧截图，再用 ffmpeg 合成视频和音轨。 3D 那支的画面是 Blender 渲染的，步骤写在 demos/04-3d-render/README.md。 字体文件没有放进仓库，需要的字体列在 assets/fonts/README.md；缺字体时画面里的字形会和成片不同。Each film is a web page that draws any frame for a given time (window.renderAt(t)); the renderer captures every frame in headless Chrome and muxes video and audio with ffmpeg. The 3D film's picture is rendered in Blender; the steps are in demos/04-3d-render/README.md. Font files are not in the repository; assets/fonts/README.md lists the ones needed. Without them the lettering will differ from the films.
